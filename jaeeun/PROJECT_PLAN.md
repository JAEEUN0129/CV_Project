# Segmentation 기반 헤어·의상 가상 피팅 프로젝트 계획

## 0. 현재 진행 상태

> 색 변경은 사진·영상 모두 완성되어 웹 화면에 연결되었다. 헤어스타일 변경은 별도 모델로
> 구현하여 영상까지 검증을 마쳤으나, 그래픽 가속이 없어 속도가 실사용 수준에 못 미친다.

| 작업 | 상태 | 비고 |

## 1단계. 개발 환경 및 프로젝트 구조

- **목표:** 협업 파일 충돌을 막고 동일한 환경에서 실행한다.
- **사용 프로그램:** Python 3.11, Git, FFmpeg, Streamlit.
- **사용 라이브러리:** PyTorch, Transformers, Diffusers, OpenCV, Pillow, NumPy, SAM 2.
- **데이터셋:** 사용하지 않음.
- **산출물:** `jaeeun/` 패키지, `.venv`, `requirements.txt`, `SETUP.md`.

## 2단계. 데이터셋 조사 및 전처리

- **목표:** 이미지와 영상을 모델 입력 규격으로 통일한다.
- **전처리:** 이미지 비율을 유지한 resize 및 padding, 영상 FPS 샘플링과 프레임 추출.
- **데이터셋 사용 계획:**
  - **LIP:** 머리카락, 얼굴, 상의 등 단일 인물 Human Parsing 학습·평가.
  - **CIHP:** 여러 사람이 있는 장면의 Human Parsing 보강.
  - **ATR / ModaNet:** 의상 부위와 패션 클래스 보강.
  - **DeepFashion2:** 의상 마스크, 랜드마크 및 의상 종류 평가.
  - **VITON-HD:** 의상 가상 피팅 결과 비교용.
  - **SA-V:** 영상 객체 마스크 전파 실험용. 인체 부위 semantic label은 없으므로 단독 사용하지 않음.
  - **자체 동의 데이터:** 실제 사용자 환경의 각도·밝기·가림 변화 평가.

## 3단계. 이미지 부위 분할

- **목표:** 입력 인물에서 머리카락, 얼굴, 상의 등 편집 부위의 마스크를 생성한다.
- **주 모델:** `fashn-ai/fashn-human-parser`.
  - SegFormer-B4 기반 공개 가중치.
  - 얼굴, 머리카락, 상의, 드레스, 바지, 팔, 손 등 18개 클래스를 출력.
- **SAM 2 용도:** Human Parser가 만든 경계를 사용자가 클릭이나 박스로 보정할 때 사용.
- **데이터:** FASHN 공식 샘플로 동작 확인 후 LIP/ATR 및 자체 이미지로 정량·정성 평가.
- **평가:** 클래스별 IoU, Dice, 추후 Boundary F1.
- **현재 결과:** 공식 샘플에서 얼굴, 머리카락, 상의, 팔, 손, 바지, 다리 등의 마스크 생성 완료.

## 4단계. 이미지 헤어·의상 편집

- **목표:** 선택한 마스크 영역만 변경하고 얼굴과 배경은 보존한다.
- **모델:** `stabilityai/stable-diffusion-2-inpainting`.
  - 마스크와 텍스트 조건을 이용해 앞머리, 길이, 의상 종류를 재생성.
  - 공개 가중치이나 OpenRAIL++ 라이선스 조건을 준수해야 함.
- **단순 색상 변경:** diffusion 대신 OpenCV의 HSV/LAB 색 변환을 우선 사용해 원래 질감과 명암을 보존.
- **데이터:** DeepFashion2/VITON-HD의 의상 예시와 자체 동의 이미지로 결과 비교.
- **검증:** 얼굴 보존, 비편집 영역 변화량, 선택 옵션 일치도, 사용자 자연스러움 평가.

## 5단계. 영상 마스크 전파

- **목표:** 첫 프레임에서 얻은 머리·의상 마스크를 전체 프레임에 안정적으로 전달한다.
- **모델:** SAM 2.1 Hiera Small.
  - 공개 코드와 체크포인트, Apache 2.0.
  - Small 모델은 속도와 정확도의 균형이 좋아 초기 프로젝트에 사용.
- **처리:** FFmpeg/OpenCV 프레임 추출 → 기준 프레임 Human Parsing → SAM 2 prompt 입력 → 전체 영상 masklet 전파.
- **데이터:** SA-V로 일반적인 전파 성능 참고, 자체 촬영 영상으로 헤어·의상 부위 안정성 평가.
- **평가:** 인접 프레임 Mask IoU, 마스크 면적 변화, 경계 흔들림, 실패 프레임 비율.

## 6단계. 영상 편집과 시간 일관성

- **목표:** 프레임마다 헤어·의상 스타일이 바뀌거나 깜빡이는 현상을 줄인다.
- **초기 방식:** 기준 프레임 편집 결과를 optical flow로 다음 프레임에 정렬하고, 새로 나타난 영역만 inpainting.
- **보정:** 이전 편집 프레임과 현재 프레임 혼합, 동일 prompt와 seed 유지, 얼굴·배경 원본 복원.
- **출력:** 처리된 프레임을 FFmpeg로 원본 FPS의 MP4로 재조합하고 원본 오디오를 다시 결합.
- **평가:** temporal consistency, flicker, 얼굴 유사도와 사용자 설문.

## 7단계. 웹 서비스 통합

- **입력:** 사진 또는 짧은 영상 업로드.
- **옵션:** 머리 색, 앞머리·길이, 상의 색·종류.
- **중간 결과:** 원본, 부위 마스크, 마스크 오버레이.
- **출력:** before/after 비교, 결과 이미지·영상 다운로드.
- **현재 연결 범위:** 이미지 업로드와 Human Parsing 실행까지 연결됨.
- **남은 연결:** 이미지 편집, 영상 처리 진행률, 결과 다운로드, 실패 처리.

## 8단계. 최종 평가

- **분할:** IoU, Dice, Boundary F1.
- **영상 안정성:** 인접 프레임 Mask IoU, optical-flow 정렬 후 일관성, flicker.
- **편집 품질:** 얼굴 보존, 비편집 영역 보존, 스타일 조건 일치.
- **사용자 평가:** 자연스러움, 동일 인물 유지, 실제 사용 의향을 5점 척도로 조사.
- **개인정보:** 자체 사진·영상은 사전 동의, 목적·보관기간 고지, 평가 종료 후 삭제.

## 권장 구현 순서

1. 헤어스타일 결과의 머리 영역 색 안정화 (프레임 간 색조 편차 축소)
2. 모양과 색을 각각 다른 참조에서 지정하도록 화면 확장
3. 헤어스타일 결과를 원본 화면에 되붙이기 (SAM 2로 경계 추적)
4. 광학 흐름 정렬 기반의 시간 일관성 지표 구현 (현재 지표는 움직임과 깜빡임을 구분 못 함)
5. 라벨이 있는 데이터로 분할 정확도 정량 평가
6. 저작권이 자유로운 참조 사진으로 교체
7. 그래픽 가속 환경으로 이전 — 남은 병목은 전부 여기에 있음
