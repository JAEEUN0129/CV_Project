# 헤어스타일 참조 사진

이 폴더의 사진 한 장이 "바꾸고 싶은 헤어스타일" 하나가 된다. 웹 화면의 헤어스타일
선택 목록은 이 폴더를 그대로 읽으므로, 사진을 넣으면 선택지가 늘고 빼면 줄어든다.
목록에 보이는 이름은 파일 이름에서 확장자를 뗀 것이다.

## 사진 조건

- 정면 얼굴, 머리 전체가 잘리지 않고 들어올 것
- 얼굴이 화면에서 크게 잡힐 것 (작으면 결과가 뭉개진다)
- 바꾸고 싶은 머리 모양과 색이 분명히 보일 것 — 모양과 색을 함께 가져온다

## 지금 들어 있는 사진에 대한 주의

현재 파일들은 모델 저장소에 예시로 딸려온 유명인 사진이다. **동작 확인용이며,
발표 자료나 공개 데모에 그대로 쓰면 안 된다.** 초상권 문제가 있다.

공개할 결과물을 만들기 전에 **저작권이 자유로운 사진으로 교체**할 것. Pexels,
Unsplash 등에서 받을 수 있다.
